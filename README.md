# GitHub Trending Pipeline
ETL pipeline that extracts trending GitHub repositories, transforms them using pandas, and loads them into Google BigQuery — orchestrated with Apache Airflow.

## 📌 Project Overview
This project is part of my learning journey transitioning from **QA Manual** to **Data Engineering**. It demonstrates:
- Building an ETL pipeline from scratch
- Working with REST APIs
- Data transformation with pandas
- Cloud data warehousing with BigQuery
- Workflow orchestration with Apache Airflow

## 🛠️ Tech Stack

| Component | Technology |
|-----------|------------|
| Extraction | Python `requests` + GitHub REST API |
| Transformation | Python `pandas` |
| Data Warehouse | Google BigQuery |
| Orchestration | Apache Airflow (Astro CLI) |
| Containerization | Docker |
| Language | Python 3.11+ |

## 📝 What I Learned
- API Integration: Handling pagination, rate limiting, and error responses
- Data Quality: Deduplication, null handling, and data validation
- Cloud Warehousing: Creating datasets, tables, and loading data to BigQuery
- Orchestration: Building DAGs, task dependencies, scheduling
- Production Practices: Logging, idempotency, containerization
- Infrastructure: Service accounts, IAM, environment variables
